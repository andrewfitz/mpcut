# MPCut audit, November 23, 2026

Fifty Sol reviewers examined the working tree, including in-progress changes. The review covered the native media libraries, Swift core, editor, CLI, Go bridge, connectors, packaging, test fixtures, benchmarks, and documentation.

## Findings and repairs

| Area | Examples of repaired behavior |
| --- | --- |
| Project safety | Sequence and multicam Save As coordinate transcript asset copies with publication. A destination collision leaves the existing project intact. Save checks the destination revision again before publishing. |
| Timing and export | Audio stepping handles unrepresentable timestamps. WAV size preflight uses the final sample width. Duplicate bulk output names are caught before writing. Cut maps preserve output gaps, and trims preserve replacement handles at retained clip edges. |
| Multicam | Preflight checks selected recording paths, validates picture spans around intentional gaps, and accounts for missing audio coverage. Pinned camera seeks report the actual recording and assembly occurrence. |
| Preview and decoding | Audio-only seeks clear stale video. MPEG-TS seeks use the requested clock. Native decoding handles corrupt frames and cancellation. Regression testing caught a change to missing-track playback and restored its silent fallback. |
| Transcripts | Interrupted jobs cannot attach unconfirmed results. Failed cache acquisitions release earlier claims. Stale asynchronous reads are rejected. Phrase selection covers overlapping endpoint words, and saved-plan parsing rejects ambiguous JSON. |
| Interchange and control | Premiere bridge requests recover after malformed input. Live review images are decoded and checked against their declared dimensions. Structured MCP export requests preserve mixed clip and range-list entries. |
| Security and lifecycle | Connector bearer-key loading checks the opened descriptor, enforces private permissions, and limits reads. Export permission checks avoid a temporary process-wide umask change. Shutdown stops new file jobs while draining active jobs. |
| Verification | Packaging rejects optimized Python invocations that could bypass its assertions. Benchmarks reap timed-out children, clean up sidecars, and verify rendered JPEG pixels. Transcript scoring handles repeated tokens and one-to-one speaker assignment. |

The app icon and eleven documentation images shrank by **1,182,797 bytes**. Validation compared decoded pixels, JPEG coefficients and the iconset extracted by macOS.

## Verification

- The default Swift run reported 472 core and 619 app tests, with **1,047 passes, 44 skips and zero failures**. Repeating the core suite with the built FFmpeg helper exercised 21 additional cases. Four real transcription-helper cases and two spoken-media extraction cases passed separately.
- Across 36 Python integration suites, 484 tests passed against the rebuilt debug CLI. They exercised packet copy, Smart Trim, damage recovery, re-encoding, audio conversion, stills, multicam, source ranges, sidecars, project authoring, and transcripts. Checks included decoded frame and sample counts, packet timing and payloads, and output publication.
- A native harness exercised repeated media probe, waveform, envelope and transcript decoding under AddressSanitizer and UndefinedBehaviorSanitizer. Neither reported an error. A separate macOS leak check reported zero leaked bytes across 20 repository fixtures. The linked FFmpeg libraries were outside the sanitizer build.
- Go tests passed under the race detector. The packaged live integration exercised an isolated desktop instance, including native Undo/Redo, queue controls, transcript rebinding and Settings relaunch. Native Resolve round trips passed. Premiere panel behavior was tested with a mock.
- The signed release bundle passed strict signature verification and validation of 207 tool descriptors and three offline guides. The release build was staged outside the repository's distribution directory.

On filesystems that lack exclusive rename, the publication fallback verifies ownership of its placeholder before replacement. A separate process can still change that path between the ownership check and rename.

# CLI and MCP feature gaps for review

Reviewed the November 23, 2026 working tree, including uncommitted features. The CLI findings cover work a script can use against media or a saved project. Live MCP findings cover working in the open editor, including its unsaved revision. Priorities reflect the impact on completing a workflow.

## Highest priority

| Capability | Affected surface | What a caller can do today | Decision for review |
| --- | --- | --- | --- |
| Edit participants in the open project | Live MCP | All 11 participant tools dispatch to file operations. The editor can scan or resume, accept geometry, link or correct appearances, bind speakers and ISO audio, review markers, and save a composition or angle take against the open revision. Generic live export can render an already-authored participant composition. | Expose the inspector’s reads and mutations using the live project handle, revision and native history. Include the IDs, time ranges and coordinates needed to review an edit. [File dispatch](../Sources/MPCutApp/MCPFileRequest.swift) · [Inspector](../Sources/MPCutApp/ParticipantInspector.swift) · [Live render](../Sources/MPCutApp/MCPOutputs.swift) |
| Reconcile a replacement recording or changed participant scan | CLI and MCP | Initial acceptance and whole-object replacement exist. Initial acceptance explicitly refuses differing accepted geometry. The GUI previews which appearances, masks, bindings and corrections are affected, distinguishes a verified copy from changed content, and lets the editor confirm coverage per person. | Expose the reconciliation report, apply the reviewed result and confirm individual coverage. This matters when deciding whether an existing privacy mask is still valid. [Acceptance guard](../Sources/MPCutCore/ParticipantProjectAcceptance.swift) · [Reconciliation operations](../Sources/MPCutCore/ParticipantProjectReconciliation.swift) · [CLI dispatch](../Sources/MPCutCLI/Participants.swift) |
| Review a participant composition before rendering a movie | CLI and MCP | The composition sheet previews a frame from the proposed plan. File render planning returns a report. CLI program-frame export and live MCP program-frame review explicitly refuse a participant render plan. A source or camera JPEG omits the composed framing and masks. | Accept an output time and a saved or proposed plan, and return the composed review image. [GUI preview](../Sources/MPCutApp/ParticipantCompositionSheet.swift) · [CLI guard](../Sources/MPCutCLI/ProgramFrames.swift) · [Live MCP guard](../Sources/MPCutApp/MCPReviewFrame.swift) |
| Apply multicam sync and revise an existing recording | CLI and file MCP | A script can request sync evidence and specify initial camera offsets at project creation. The saved-project editor has no action to update an existing recording’s offset. It also lacks the live actions to rename, relink, reorder or change the source microphone, revise the group end, or set or clear audio for a specific switch. Mix lanes, program audio and replacement-track offsets already have saved-project actions. | Start with applying a reviewed source offset, which closes the sync workflow. On a disposable project, sending the live action name `offset` to `project edit` returned `Unknown multicam action offset`. [Saved actions](../Sources/MPCutCLI/ProjectAuthoring.swift) · [Live actions](../Sources/MPCutApp/MulticamMCP.swift) · [GUI sync](../Sources/MPCutApp/MulticamSyncSheet.swift) |

## Other gaps for scripted work

| Capability | Affected surface | Gap and existing coverage |
| --- | --- | --- |
| Dialogue-driven participant switches | CLI and MCP | The GUI generates proposals from bound transcript speakers with minimum-hold, overlap and offscreen policies. Scripts can take a known angle at a known time. They cannot request the native proposals with their occurrence and reason, or accept a reviewed proposal through that workflow. [Dialogue review](../Sources/MPCutApp/ParticipantDialogueReview.swift) · [CLI commands](../Sources/MPCutCLI/CommandPath.swift) |
| Manage analysis caches | CLI and MCP | Inspect and build support a source, project context and resolved locations. The GUI also selects the storage mode and cache disk, discovers copies by folder, previews reclaimable bytes and retained material, clears rebuildable analysis, and separately removes whole sidecars. These management actions are absent from the public commands and tools. [Cache settings and cleaner](../Sources/MPCutApp/SidecarStorageSettings.swift) · [CLI inspection](../Sources/MPCutCLI/Sidecar.swift) · [MCP preference keys](../Sources/MPCutApp/MCPResources/lifecycle.json) |
| Recover a moved transcript store | CLI and MCP | The GUI can point an existing attachment at a recovered store. Import, track rebinding and recognition-job reconciliation are available for other purposes. No public operation invokes attachment-store recovery with the replacement directory. [Recovery handler](../Sources/MPCutApp/LiveTranscriptController.swift) · [GUI action](../Sources/MPCutApp/TranscriptPane.swift) · [MCP handlers](../Sources/MPCutApp/MCPTranscript.swift) |
| Protect a multicam pause while shortening | CLI and file MCP | Live review protects a group-time pause across its repeated occurrences. The CLI accepts individual retained durations and honors authored transcript protection, but explicitly rejects `--protect-pause` for multicam. Confirmed on a disposable project. [CLI guard](../Sources/MPCutCLI/main.swift) · [Multicam planner inputs](../Sources/MPCutCLI/ProjectSilence.swift) · [Live review](../Sources/MPCutApp/MCPAnalysis.swift) |
| Work with history retained in one saved project | CLI and file MCP | The GUI and live MCP can inspect and restore a retained state. Headless `history compare` requires two files and compares their current timelines. A script cannot select a retained revision for comparison or restore it to a new project through the history command. [CLI comparison](../Sources/MPCutCLI/TimelineReview.swift) · [GUI history](../Sources/MPCutApp/ProjectHistoryView.swift) |
| Discover and reconcile transcription jobs | CLI and file MCP | The GUI and live MCP list project jobs and reconcile a recognition job for an attachment. The CLI can prepare, run, check, cancel and retry jobs by ID, and import their results. It has no project job-list operation or counterpart to live attachment-job reconciliation. [Live job handlers](../Sources/MPCutApp/MCPTranscript.swift) · [CLI job operations](../Sources/MPCutCLI/Transcript.swift) |
| Name recurring scene views | CLI and file MCP | Live MCP and the GUI can rename or reset a recurring view. Headless commands scan and group scenes, but have no rename action. The CLI scene-export reader accepts a report containing `view_label`, drops the supplied label while decoding, and derives its export label from the numeric view ID. [Live rename](../Sources/MPCutApp/MCPAnalysis.swift) · [Scene export](../Sources/MPCutCLI/SceneExport.swift) |

## Open-editor controls missing from MCP

| Capability | Why it matters |
| --- | --- |
| Dismiss Project History | `history_panel_show` sets the history sheet visible. The session treats that sheet as modal and gates actions including save and add media. The GUI has Cancel. The MCP notice-dismiss handler only handles editor notices. An agent that opens History has no matching close action to resume this workflow. [Lifecycle](../Sources/MPCutApp/MCPLifecycle.swift) · [Modal state](../Sources/MPCutApp/ProjectSessions.swift) |
| Open and inspect the Feeds panel | The multicam editor recognizes the `participants` inspector section, but the published schema excludes it. A test call failed schema validation before reaching the editor. Sequence Feeds has a dedicated visibility flag which the layout tools neither report nor set. [Layout schema](../Sources/MPCutApp/MCPResources/presentation.json) · [Live presentation](../Sources/MPCutApp/MCPPresentation.swift) · [Sequence toggle](../Sources/MPCutApp/EditorView.swift) |
| Start a still-only timeline in an empty window | The GUI accepts the first still and asks for format, cadence and color. Live still insertion requires an editable picture timeline. Generic remote media import bypasses the native image-import branch. The CLI and file MCP can create a saved still project and MCP can open it. [GUI import and format](../Sources/MPCutApp/EditorModel.swift) · [Live still preconditions](../Sources/MPCutApp/MCPStills.swift) |
| Set visible reader and window preferences | MCP can show the transcript, set zoom and change native split sizes. It cannot toggle the full-height sidebar, set the visible reader’s Follow Playback state or remembered speaker-to-camera preference, or list and clear Open Recent. These are lower-priority desktop controls. [Sidebar](../Sources/MPCutApp/EditorWorkspace.swift) · [Reader](../Sources/MPCutApp/TranscriptPane.swift) · [Recent files](../Sources/MPCutApp/RecentFiles.swift) |

Queried CLI JSON help and MCP `tools/list`, checked the Feeds schema rejection, and exercised two CLI rejections against generated media and a temporary project. Tool counts describe discovery. Live edits and media renders were assessed from their implementations, without driving every interaction in a running editor. Bundle observations refer to the local artifacts at review time.

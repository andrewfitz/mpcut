# CLI and MCP feature gaps for review

## Packaged build

Runtime discovery on the rebuilt checkout returned **325 MCP tools, 133 in files-only mode, and 131 CLI help entries**. Each advertised input schema matched its checked-in descriptor. The source inventory found 740 literal GUI control labels across 48 files, and all 260 documented command paths matched CLI help. The table records what changed for the six priority workflows.

| Workflow | Current behavior |
| --- | --- |
| Resume after a disconnect | The standalone worker reserves each operation UUID before launching a command. Reconnection with the same UUID retrieves the recorded outcome or reports `outcome_unknown` if the original worker died before recording completion. The worker refuses to execute that operation again during its seven-day retention window. `file_job_release` frees a collected payload and preserves the receipt. [Recovery and retention](HEADLESS.md) |
| Verify a mask or tile assignment | History comparison now reports `participant_changes` with source, tile and affected source-clock interval or point. The live comparison pages those changes together with ordinary timeline changes. The integration fixture moves a covered box and verifies both the reported interval and the independently decoded output pixels. [Comparison](../Sources/MPCutCore/TimelineParticipantComparison.swift) · [Pixel regression](../Tests/Integration/parity_workflows.py) |
| Publish a reviewed export | Dry-run an ordinary render against a saved project. Pass the returned `plan_token` to render with the reviewed archive, source identities, settings, destination and executable build. A stale token stops publication, including when the project changes during encoding. Existing callers can still render directly. [Render guard](../Sources/MPCutCLI/ProjectRenderReview.swift) · [Publication regression](../Tests/Integration/project_convert.py) |
| Choose a compatible installation | `mpcut --version --json` and `cli_version_read` expose the build UUID, supported project schema and detector capabilities. **Schema 9 remains strict by explicit decision.** Earlier formats still require a compatible installation. [Version fields](CLI.md#help-and-version) |
| Inspect a saved frame | `review_file_frame_read` starts a file job. After success, `review_file_frame_result_read` returns one JPEG image block and its frame metadata. Source, sequence, group and assembly clocks are covered. Frame export to disk also accepts PNG and TIFF on eligible inputs. [Frame tool schemas](../Sources/MPCutApp/MCPResources/file_frame.json) |
| Move media needed by Undo | Saved media list and locate expose `include_history`. Locate can apply unique matches to a copy or in place. ### Additional workflows

- **Tiles and multicam editing.** Read, stage, accept or discard pending Tiles choices. Retry live Tiles edits using the same operation ID. Apply a batch of proposed switches against one reviewed project revision, configure existing cameras and assign a transcript voice to a camera. [Headless editing](HEADLESS.md)
- **Transcript and analysis.** Discover durable recognition jobs by project, reconcile timing changes and expand word selections to a sentence, speaker turn or preceding question. Save reviewed multicam pauses and room-tone calibration. To rename a recurring scene, pass its full-source `report_id` from the same scan as the view ID. Live MCP now requires this field. [CLI guide](CLI.md) · [MCP reference](MCP-REFERENCE.md)
- **Output and storage.** Read and edit the project’s saved output settings. Preview cache contents and reclaim selected files using the token from the preview. [Headless workflows](HEADLESS.md)
- **Live editor.** Close history and save immediately, create the first still in a blank editor, set the Source or Output monitor, manage panel docking, set transcript preferences, and list or clear recent documents. [MCP coverage](MCP-COVERAGE.md)

The Git merge driver stays CLI-only. Git supplies three working files and expects the driver to replace its OURS file. The public project-document reader serves the separate need to inspect a saved project over MCP. The current checkout package is `dist/MPCut.app`, with TileTrail enabled and schema support `[9]`. The matching connector archives are in `dist/desktop-plugins/` and this package’s debug symbols are in `dist/symbols/`. The build matrix below records the November 24 baseline before implementation and cleanup. Run the CLI inside the app you intend to use to identify it.

### Verification

The files-only integration and the three parity regressions passed against the rebuilt helper and CLI. The regressions reconnect after an in-place edit, compare a privacy change with independently decoded pixels, and reject a stale ordinary render. Packaged live tests also exercised pending Tiles review, closing history before saving, and taking a transcript selection through queueing and export. Both sequence and multicam readers returned `unsupported_cut_version` for schema 8 and schema 10 test documents. [Headless fixture](../Tests/Integration/headless.py) · [Parity regressions](../Tests/Integration/parity_workflows.py)

On muted Backstage, the core suite ran 809 tests with 32 skips and zero failures. The desktop suite ran 760 tests with 10 skips and two failing reverse-playback cases. After correcting end-of-playback detection and offline test scheduling, both affected suites passed on the rebuilt checkout, 15 tests in total. The Go tests and the generated MCP reference check also passed.

## Review baseline before implementation

Reviewed November 24, 2026 against the uncommitted working tree on top of `b539b58`. The tree differs from that commit in more than 250 files, and the schema 9 project format in priority 4 exists only in the uncommitted code. The rebuilt helper advertises **293 tools, including 112 in files-only mode**. The rebuilt CLI advertises **114 help entries**, including command families. A saved Check Tiles review now carries its choices into automated acceptance, and a quote can go from transcript search to a rendered excerpt entirely through files-only MCP. The largest remaining risks for an agent occur *between* supported operations, when it resumes after losing a connection, verifies an edit, or hands an approved export to a worker.

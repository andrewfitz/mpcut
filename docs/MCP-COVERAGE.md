## File workflows and completeness checks

Use the desktop connection or the standalone file worker for saved media and projects. [Headless editing and verification](HEADLESS.md)

| CLI command or family | MCP equivalent |
| --- | --- |
| `help`, `--version`, `help multicam` | Use `cli_help_read` to discover command paths, options, examples or the multicam template. Use `cli_version_read` for the installed CLI version. |
| `media inspect`, `project inspect`, `waveform envelope read` | Use `media_file_inspect` for streams, packets and frames, `project_file_inspect` for saved edits, and `waveform_file_envelope_read` for audio. |
| `timeline range map`, `history compare` | Use `timeline_file_range_map` and `history_file_compare` for saved projects. Use `timeline_editor_range_map` and `history_editor_compare` for the current editor or its retained history. |
| `multicam sync suggest`, `multicam switch coverage` | Use `multicam_file_sync_suggest` and `multicam_file_switch_coverage_read` for saved projects. Use `multicam_sync_suggest` and the `switch_coverage` section of `multicam_state_read` for the live editor. |
| `transcript` | Use the matching saved-file transcript tool, such as `transcript_file_words_search`. For an open edit use `transcript_editor_words_search`. |
| `still`, `timeline clips space` | Use the live placement tools or `timeline_clips_space`. Use the saved-file still and timeline tools to author them directly in a saved project. |
| `project media refresh` | `project_file_media_refresh` checks saved media references. `project_editor_media_refresh` checks the open edit. |
| `scenes`, `silence`, `review frames export`, `analysis sidecar` | Choose the requested scan, plan or export, for example `silence_file_plan`, `review_file_frames_export` or `analysis_file_sidecar_inspect`. |
| `export` | Render projects, join clips or ranges, replace soundtracks, or write separate range files using the matching file export tool. |
| `project convert`, `project resolve export`, `project resolve import` | Convert an editable file with `project_file_convert`. To write an interchange timeline use `project_file_resolve_export`. To import it into Resolve use `project_file_resolve_import`. |

To check a new control, compare its behavior in the editor with the installed tool schema and a fixture request. For changes to file tools, compare the request and the completed job result with the bundled CLI.

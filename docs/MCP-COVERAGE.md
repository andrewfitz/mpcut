## File workflows and completeness checks

Provide typed file operations using the existing CLI’s structured results or its underlying core services. Expose the public options, input variants, defaults, dry-run behavior and returned fields for each applicable command. File jobs must pass the same local-control setting check as live operations. Running a file operation against a saved path reads the saved version. Every request targeting unsaved work uses the live document handle. Return structured data for clipboard/report actions, typed paths for file pickers, and the resulting edit for equivalent menu, drag and keyboard actions.

| CLI help topic | MCP equivalent |
| --- | --- |
| `help`, `version` | Discover capabilities, help topics/manual, options, examples and installed versions. |
| `inspect`, `waveform` | Inspect media/project and query timeline, packets, frames and stream envelopes. |
| `multicam` | Provide the project template/help and route its documented workflows to project, inspection, silence, frames and export operations. This CLI topic is help-only. |
| `scenes`, `silence`, `frames`, `sidecar` | Typed analysis, saved-report input, review image and cache operations. |
| `export`, `rearrange`, `bulk` | Render or dry-run the corresponding ordered input, source/range, track-selection and batch variants. |
| `convert`, `resolve` | Convert editable files or send an editable timeline, including the Resolve structured-input form. |

During implementation, maintain a mapping from each public menu, inspector action, panel option, timeline gesture outcome and CLI help option to an MCP schema field or tool and parity test. Use the app command definitions, editor views/panels, usage guide, and machine-readable CLI help as inventory inputs. Capture dynamically populated choices from the model. Assert every mapped tool appears in discovery and accepts a representative real request. Compare results for ordinary video, audio-only, multicam, and saved-file workflows. A platform- or media-dependent feature reports availability and the actual prerequisite. Record outstanding variants explicitly until their tests pass.

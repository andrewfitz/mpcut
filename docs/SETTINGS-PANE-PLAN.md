# MPCut Settings redesign

Make ⌘, the place to answer two questions an editor has while working. “Where can I change how MPCut behaves?” and “How can I start the next edit, transcription or export with my usual choices?” Ship the first answer independently of the second.

## What the editor sees today

I opened both tabs in the packaged desktop app. General opens with the local MCP switch and its status. Playback and Export defaults sit below the visible area. Analysis groups sidecars and silence detection. The working tree’s Settings view fixes its content at 480 × 495 points and already adds source-time ticks, sidecar destinations, disk availability and cache clearing. The plan includes those additions in the starting inventory. [Current pane](../Sources/MPCutApp/EditorSettings.swift) · [Storage controls](../Sources/MPCutApp/SidecarStorageSettings.swift)

All 16 keys in `EditorPreferences.Key` already have a UI in the working-tree pane. Five other saved choices belong there too.

| Saved choice | How an editor finds it today | Proposed home and factory value |
| --- | --- | --- |
| Full-height side panel | Dock button on the side panel | Editing → Panel position. Above timeline. |
| Multicam track label width | Drag the label divider or use the workspace layout command | Editing → Multicam track label width. 172 pt, adjustable from 106–360 pt. Constrain the displayed width to the space in each window. |
| Force SDR in the editor viewer | Right-click the editor picture | Playback & Monitors → Editor viewer. Automatic. |
| Force SDR in the Video Monitor | Right-click the separate monitor | Playback & Monitors → Video Monitor. Automatic. |
| Monitor clean feed | Right-click the separate monitor | Playback & Monitors → Clean feed. Off. |

Keep the divider, dock button and context menus. They are the quickest way to adjust something one can see. A change from any of them should appear in Settings and in every affected open window. Today the preview surface reads defaults when assigned its role and writes changes directly to standard defaults. The width uses another direct read/write path in MCP. ## Proposed window

Use the existing native Settings scene with a resizable sidebar and a scrollable grouped form. Start on **Editing** on first use and reopen the last visited section. Aim for 760 × 560 points initially. Let the sidebar and form work at smaller sizes with wrapping labels. Put units next to numeric fields and use native pop-up buttons, switches and steppers. Every page should be usable with no project open.

| Sidebar item | First release | Additions after the reorganization |
| --- | --- | --- |
| **Editing** | Panel position and track label width. Timeline snapping, source-time ticks, thumbnail and waveform size. Undo/redo limit and the warning before a manual edit lowers the export tier. | Show cut sections in new sequence windows. Initial durations for inserted stills and color gaps. |
| **Playback & Monitors** | Scrub audio, mute and preview volume. Independent Automatic / Force SDR pickers for editor and monitor. Clean feed with the explanation “Hide status overlays and window controls on the Video Monitor.” | Starting forward playback speed. |
| **Media & Analysis** | Refresh changed recordings. Reuse analysis, destination for new sidecars, shared cache folder, availability and Clear Caches. Keep minimum pause, ignored sound duration and padding per side together under Silence. | Use the existing storage and silence controls as supplied. |
| **Transcripts** | Introduce this page with the first transcript defaults. | Preferred recognition engine and language. Follow Playback when first opening a reader. |
| **Export** | Default movie mode and JPEG preset. | Re-encode codec and quality. Starting folder for movie, JPEG and queued exports. |
| **Automation** | Local MCP control, current listener status and the existing explanation of access. | Include the local setup guide alongside status. |

Make pages reachable by keyboard. Add settings search when the new fields land. Searching “HDR” should reveal both display pickers, “cache” should reveal the location and clearing controls, and “undo” should reveal the history limit. A result opens its page, scrolls the control into view and focuses it. A search for “export tier” should find the warning in Editing as well as the movie mode in Export. This lets the warning live beside the action that triggers it.

## New defaults worth implementing

Give each default a factory value, a point at which MPCut reads it, and a visible override where the editor does the work. The following order favors repeated choices that already have working controls.

| Priority | New preference and factory value | Behavior |
| --- | --- | --- |
| 1 | **Re-encode video** — H.264, Balanced. **ProRes quality** — 422 when ProRes is selected. | Seed the sequence and multicam single-export and queue forms wherever they offer codec selection. Use the existing codec-specific quality lists. Keep track, container, audio, still-placement and tier eligibility under the export rules. Show the effective selection and retain existing alternatives when an output is ineligible. |
| 1 | **Start export panels in** — Automatic, with an optional Chosen folder. | Automatic keeps each entry point’s current directory behavior. Chosen folder supplies the initial directory for a fresh session. A folder explicitly chosen during that session takes precedence on subsequent exports. If the configured folder is offline or inaccessible, open the normal panel at its automatic location and identify the unavailable folder in Settings. The save panel still owns the final filename and destination. |
| 1 | **Transcription engine and language** — Automatic for each. | Populate a new Transcribe Audio setup. Automatic uses the existing capability lookup, which prefers available Qwen3, then the first available engine. Automatic language omits the override. If a saved engine is unavailable, show the reason and the available selection in setup while retaining the preference for later. A retry uses its job’s captured options. Keep model downloads and speaker/track assignments in job setup. |
| 2 | **Inserted still duration** and **Color gap duration** — 2 s each. | Interview stills and spacing can have different rhythms. Seed Insert Still separately from Insert Color Gap and fixed-duration Space Clips in both editors. Convert to a valid whole-frame duration at the active cadence, including fractional frame rates. Source Timing continues to derive gaps from the recordings. |
| 2 | **Starting playback speed** — 1×. | Initialize forward speed once for a new sequence or multicam transport using the existing speed choices. The Playback menu and shortcuts continue to adjust that window. Opening Settings or changing the default during playback must preserve the current rate and playhead. |
| 2 | **Show cut sections** — On. **Follow Playback in transcripts** — On. | Seed the first sequence timeline view and the first transcript reader respectively. The local eye and Follow Playback controls remain available. When reopening a hidden reader, restore its remembered location and follow state before consulting defaults. |

The export paths already have separate sequence and multicam option types, and the sequence editor remembers some choices during a session. Thread the new values into the opening paths and preserve more specific choices, including an explicit File → Export mode. Keep field edits in a sheet local. Opening or cancelling a sheet should never update an app default. The transcript reader restores its per-window place, while job setup chooses an engine after asking the provider what is available. ### Which choices should stay close to the work?

- A speaker’s suggested camera angle is keyed by transcript attachment and speaker. Give an editor access to that mapping with its dialogue. A single default camera in Settings would point at different material in each project. The same applies to source-specific room-tone calibration, audio routing and participant bindings. [Angle suggestions](../Sources/MPCutApp/TranscriptPane.swift) · [Silence calibration](../Sources/MPCutApp/MulticamAnalysis.swift)
- Playhead, marks, zoom, panel visibility, current monitor display and Skip Pauses belong to the current window or review session. File → Open Recent owns the list of paths and its Clear Menu action. [Window presentation](../Sources/MPCutApp/MCPPresentation.swift) · [Recents](../Sources/MPCutApp/RecentFiles.swift)
- Two candidates for a later pass are a **new still-only timeline format** preset, currently initialized to 1920 × 1080 at 30 fps, and **participant dialogue review defaults**, currently one second minimum hold with Hold the Shot for overlap and offscreen speech. Add these if those workflows warrant more controls. Actual project formats, participants, shots and approved edits stay with their project. [Still format dialog](../Sources/MPCutApp/StillTimelineFormatPanel.swift) · [Dialogue review](../Sources/MPCutApp/ParticipantDialogueReview.swift)

## Implementation and acceptance

1. **Reorganize and connect the existing preferences.** Split the current form by page. Keep the existing stored key names, encodings and factory values, including the two independent SDR booleans. Route the five scattered settings through the shared, injected preferences instance. Connect both preview surface types, both panel placements, divider drags and the existing MCP width command. Preserve the separate sidecar configuration in MPCutCore, which the desktop and CLI already share. Preserve the history field’s commit-on-finish behavior when navigating pages or closing Settings. Acceptance: an upgraded profile sees its previous values, both editors react to a live change, and the monitor can be configured before it is opened.
2. **Ship export and transcription defaults.** Factor preference seeding into the existing sheet constructors so toolbar, menu and queue paths agree. Snapshot settings when a fresh sheet or job is created. Keep source-specific export rules, existing session overrides, explicit command arguments and recorded jobs authoritative. Keep the desktop folder choice local to save panels. Acceptance: choose ProRes and a transcript language, open fresh sequence and multicam jobs, override once, cancel or finish, then open another session and see the saved defaults. Exercise a missing engine, an offline export folder, audio-only output and a timeline with still placements.
3. **Ship editing and playback defaults and search.** Use one frame-aware calculation for the duration fields. Initialize transport and presentation values once per owner. Add search synonyms to the same page/row definitions used to navigate and label the controls. Acceptance: two open editors can play at different speeds. A 23.976 fps insertion lands on a valid frame. A hidden transcript returns to its prior place and follow state. Keyboard and VoiceOver users can find Force SDR, edit a duration and return to the editor.
4. **Verify compatibility with each slice.** Extend the existing preference, presentation, sidecar and lifecycle tests. Exercise isolated defaults suites, invalid stored values, temporary launch overrides, relaunch with existing keys, and Settings with zero, one and two projects. Keep the public MCP preference list, validation and reference consistent with the supported app-wide values. Local MCP enablement remains a user-controlled switch. Keep UI navigation state and chosen-folder access out of the public value list, with explicit coverage for that distinction. Preserve current CLI defaults and existing live MCP behavior. Update Settings paths in the usage, naming and agent guides and the packaged desktop smoke tests as the controls move. [Preference tests](../Tests/MPCutAppTests/EditorPreferencesTests.swift) · [MCP lifecycle contract](../Tests/MPCutAppTests/MCPLifecycleTests.swift) · [Sidecar tests](../Tests/MPCutAppTests/SidecarStorageSettingsTests.swift)

The first release can stop after step 1 and its compatibility checks. It gives every existing app-wide editor preference a discoverable home without waiting on export or transcription work.

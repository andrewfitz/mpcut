# Live editor workflows

Resolve the window with `project_windows_list`, read `project_editor_state_read`, and page long timelines with the observed revision. Check each tool's availability in the connected build.

| What the editor wants | Tools and decisions |
| --- | --- |
| Open, create or recover an edit | Use `project_open` with the absolute `project_path` for a saved project, `project_create` for a new window and `project_media_add` for an existing timeline. Use `project_drafts_list` and pass the chosen `draft_path` to `project_draft_recover`. Use `project_window_focus` to bring a window forward when requested. |
| Save or close | `project_save` takes a destination in `project_path` for an untitled edit or Save As. For `project_close`, resolve the save/discard decision for a dirty window. `workspace_notice_dismiss` handles a supported notice on the identified window. |
| Trim, rearrange or apply a CSV | Use `timeline_item_split` inside the target occurrence. Use `sequence_clip_edit` for a trim, move or CSV import. Use `timeline_selection_set` for marks and `sequence_range_edit` to delete across clips. Check the occurrence order and resulting durations. |
| Save a source select or assemble ordered ranges | Use `source_selects_list` and `source_select_save` to keep named intervals. Pass ordered raw ranges or saved select IDs to `sequence_source_ranges_apply`. Equal sequence bounds insert, and an interval replaces the covered material. |
| Match notes to a cut | Use `timeline_editor_range_map` for every intersecting source or program piece. For an older retained cut, resolve its token and index through `history_read`. Use `history_editor_compare` to inspect changes from that state to the current edit. |
| Inspect or restore history | Read `history_read`, use `history_undo` or `history_redo` for a single step, or `history_state_restore` with an index and history token from the same snapshot. `history_panel_show` opens the editor's history sheet. Use `history_panel_close` before saving. |
| Navigate and monitor | Seek with `timeline_playhead_seek`, start playback with `playback_transport_play` and stop with `playback_transport_pause`. Read a JPEG with `review_editor_frame_read`. Inspect layout with `workspace_layout_read`, adjust it with `workspace_layout_set`, open panels with `workspace_panel_show` and reveal a time with `timeline_time_reveal`. `playback_monitor_visibility_set` controls the monitor window. Use the `set_monitor_picture` action on `workspace_layout_set` to select Source or Output in the editor viewer. The same tool controls cut-section visibility, full-height docking and transcript Follow Playback. |
| Set up cameras and audio | For a pending setup, inspect `multicam_setup_read` and call `multicam_setup_confirm` with the chosen sources or `multicam_setup_dismiss` to close setup. Use `multicam_state_read` to read existing sources and switches. `multicam_source_edit` handles relink, order, sync offsets and nudges. `multicam_group_end_set` sets the group end. `multicam_program_audio_set` sets program routing, including a fixed source and absolute stream index. |
| Align media or check a camera take | Use `multicam_sync_suggest` to read timestamp and waveform evidence. Review the candidate before applying an offset. Inspect `multicam_state_read` with section `switch_coverage` to find picture and routed sound gaps before a group switch. For a picture override on one replay, use `multicam_assembly_edit` with `angle_set` or `angle_clear`. |
| Cut or audition multicam | `multicam_preview_control` auditions a camera or returns to program. `multicam_camera_take` changes picture at group time. `multicam_switch_edit` adjusts an existing switch or its audio override. Use `multicam_selection_set` to select an assembly occurrence or range, then `multicam_assembly_edit` to append, move, trim or remove it. |
| Review sound and dead air | Read `analysis_editor_state_read` for sources and tracks. Use `preferences_set` with `key: "silence_padding_per_side_seconds"` and a numeric `value` for how much silence to keep on each side. Use `key: "silence_max_blip_seconds"` and `value: 0.30` to ignore a click of up to 300 ms between quiet stretches. Each setting change takes a fresh `operation_id`. Calibrate a marked sample with `silence_threshold_calibrate_from_marks`. Run `silence_editor_scan`, poll `analysis_job_status_read`, then list and audition pauses. Use `silence_editor_takes_queue` for retained takes or `silence_editor_pauses_shorten` to change the edit. |
| Correct take boundaries or audition an existing cut | Read `silence_editor_take_candidates_list` and use `silence_editor_take_boundary_edit` in its reported clock. Set an individual pause length with `silence_editor_pause_review` action `set_retained`. Use `timeline_editor_join_preview` to audition an existing incoming join or multicam switch. |
| Find shots and reuse analysis | For a scene scan, follow the receipt and read `scenes_editor_boundaries_list`. Verify a recurring view from its picture and pass the full-source `report_id` to `scenes_view_rename`. `analysis_editor_sidecars_save` persists completed analysis. Where offered, `project_editor_media_refresh` checks changed recordings and reports affected references. |
| Find and edit dialogue | Use `transcript_editor_attachments_list` to inspect results and `transcript_editor_words_search` to search on the requested clock. For repeated lines, resolve the occurrence and attachment. Use `transcript_editor_edit_plan` to plan a word edit or named excerpt, then apply or queue the reviewed plan using the same revisions and result identity. Use `transcript_editor_excerpt_save` to write the queued excerpt as an editable project. |
| Import, transcribe or export dialogue | Use the corresponding `transcript_editor_attachment_*` tool to import, bind, detach or export transcripts. Use `transcript_provider_capabilities_read` and `transcript_tracks_list` to choose local Transcriberrr inputs, then start recognition when requested. Save the returned `job_id`, poll status, and check track coverage and whether the result attached. Use list to find durable jobs after reopening. Poll transcript and excerpt exports with `export_editor_job_status_read`. |
| Add or remove gaps between picture items | Use `timeline_clips_space` with a uniform rational `duration` or `source_timing: true` for chronological, nonoverlapping ranges of the same source or group. Use duration zero to remove interior gaps. Read the result with `still_editor_placements_list`. |
| Revise stills | Page `still_editor_placements_list` at the current revision. `still_editor_placement_insert` adds a timed image, `still_editor_picture_replace` covers picture over existing sound, and `timeline_gap_insert` adds a gap. `still_editor_placement_update` adjusts framing, timing or fragments. `still_editor_placement_remove` acts on a placement. `still_editor_asset_relink` changes the asset shared by its placements. |
| Deliver media | Preflight the live project with `export_editor_project_plan` and use `export_editor_project_render` to write a movie. `export_editor_boundary_apply` commits a reviewed boundary adjustment. For separate cuts, add ranges with `export_queue_range_add`, preflight with `export_queue_plan` and write the files with `export_queue_render`. Use `review_editor_frames_export` for JPEGs and a timestamp manifest. |
| Review queued contents | Use `export_queue_list` to inspect captured files and trims. Use `export_queue_entry_rename` for a name change or `export_queue_entry_revise` with current marks to recapture the edit. For an occurrence-level delivery record, read `cut_map` in the project export result. |
| Replace sound or hand off an edit | For a sequence, `sequence_source_soundtrack_replace` produces a working movie and applies the replacement to the edit. For multicam, use `multicam_program_audio_set` with `mode: "replace"` to replace the program soundtrack and clear switch-level sound overrides. `project_editor_convert` converts the current revision to an editable project. Use `project_editor_resolve_export` to write interchange or `project_editor_resolve_import` to also import it into Resolve. Report the written paths and the separate import outcome. |

For live output receipts use `export_editor_job_status_read` and, to stop that job, `export_editor_job_cancel`. For analysis use `analysis_job_status_read` and `analysis_job_cancel` with the specific receipt. Use `scenes_editor_scan_cancel` for scene scans and `silence_editor_scan_cancel` for silence scans. For an operation started in MPCut's GUI, use `project_operations_list` and, if asked to cancel, `project_operation_cancel` with the returned identifier and matching project scope. Follow cancellation through its terminal state and check any published outputs.

# Live editor workflows

Resolve the window with `list_projects`, read `get_editor_state`, and page long timelines with the observed revision. Check each tool's availability in the connected build.

| What the editor wants | Tools and decisions |
| --- | --- |
| Open, create or recover an edit | Use `open_project` for a saved project, `new_project` for a new window and `add_media` for an existing timeline. Use `list_drafts` and pass the chosen draft path to `recover_project`. Use `focus_project` to bring a window forward when requested. |
| Save or close | `save_project` takes a destination for an untitled edit or Save As. For `close_project`, resolve the save/discard decision for a dirty window. `dismiss_notice` handles a supported notice on the identified window. |
| Trim, rearrange or apply a CSV | Use `split_at` inside the target occurrence. Use `sequence_control` for trim preview, move, marks, deletion across clips and CSV split points or keep ranges. Check the occurrence order and resulting durations. |
| Inspect or restore history | Read `get_history`, use `undo` or `redo` for a single step, or `restore_history` with an index and history token from the same snapshot. `show_history` opens the editor's history sheet. |
| Navigate and monitor | Use `seek` and `set_playback` for the playhead and transport, `review_frame` for an inline JPEG, and `get_presentation` / `set_presentation` for window layout. `set_video_monitor` controls the monitor window. Read `get_preferences` before a requested app-wide `set_preference` change. |
| Set up cameras and audio | For a pending setup, inspect `get_multicam_setup` and complete `multicam_setup` with the returned source IDs. Use `get_multicam` to read existing sources and switches. `multicam_source` handles relink, order, sync offsets and nudges. `multicam_group` sets the group end. `multicam_audio` sets program routing, including a fixed source and absolute stream index. |
| Cut or audition multicam | `multicam_preview` auditions a camera or returns to program. `set_camera_at` changes picture at group time. `multicam_switch` adjusts an existing switch or its audio override. Use `multicam_select` to select an assembly occurrence or range, then `multicam_assembly` to append, move, trim or remove it. |
| Review sound and dead air | Read `analysis_state` for sources and tracks. `get_waveform` returns signed low/high bins, while `get_waveform_peaks` reads cached peak bins. Use `configure_silence` or calibrate with `use_room_tone`, run `scan_analysis`, then `list_pauses` and `review_pause`. `set_skip_pauses` changes playback. `apply_pauses` queues takes or shortens the edit. |
| Find shots and reuse analysis | For a scene scan, follow the receipt and read `list_scenes`. Verify a recurring view from its picture before using `rename_view`. `save_analysis_sidecars` persists completed analysis. Where offered, `refresh_project_media` checks changed recordings and reports affected references. |
| Revise stills | Page `list_stills` at the current revision. `add_still` inserts or replaces picture. `update_still` adjusts framing, timing or fragments. `remove_still` acts on a placement. `relink_still` changes the asset shared by its placements. Check program picture and duration after the change. |
| Deliver media | `render_project` preflights or renders a live scope. `apply_export_review` commits a reviewed boundary adjustment to the timeline when requested. For separate cuts, use `add_export_range`, `get_export_queue`, `remove_export_range` and `export_queue`. For review JPEGs and a timestamp manifest use `export_review_frames`. |
| Replace sound or hand off an edit | For a sequence, `replace_live_audio` produces a working movie and applies the replacement to the edit. For multicam it sets the program soundtrack. `convert_live_project` converts the current revision to an editable project. `send_live_to_resolve` writes interchange and optionally imports it. Report the written paths and the separate import outcome. |

For live output receipts use `live_job_status` and, to stop that job, `cancel_live_job`. For analysis use `analysis_job_status` and `analysis_job_cancel` with the specific receipt. `cancel_analysis` targets a scan family. For an operation started in MPCut's GUI, use `get_native_operations` and, if asked to cancel, `cancel_native_operation` with the returned identifier and matching project scope. Follow cancellation through its terminal state and check any published outputs.
